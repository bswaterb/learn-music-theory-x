# 🎵 乐理入门 · 从零开始的交互式乐理手册

一套写给**零基础新手**的乐理入门教程，以网页形式呈现：每个概念都配有可以点击播放的例子、可以弹奏的钢琴键盘和会发声的五线谱/简谱，并附带 9 个配套练习工具。

所有声音都由浏览器（Web Audio API）实时合成，**不需要联网、不需要安装任何东西**。

## 怎么打开

**最省事：桌面图标「乐理入门」**

桌面上的「乐理入门」（紫色音符图标）双击一下，就会在后台启动本地服务，不弹终端窗口，然后用默认浏览器打开网站。服务已经在运行的话，会直接打开网站。也可以把它拖到程序坞（Dock）里。

如果移动了项目文件夹，或者想放到别的地方，在项目目录里运行下面的命令重新生成即可：

```bash
sh scripts/make_launcher.sh              # 生成到桌面
sh scripts/make_launcher.sh /Applications  # 或者放进"应用程序"
```

**方式一：一键启动脚本**

- macOS：在"访达"里双击 **`start.command`**。它会打开一个终端窗口运行本地服务，并自动用浏览器打开网站。
- 终端：在项目目录里运行 `./start.sh`。

| 想做什么 | 命令 |
|---|---|
| 启动并打开网站（已在运行就直接打开） | `./start.sh` |
| 后台启动，不占终端窗口 | `./start.sh --bg` |
| 停止 | `./start.sh stop`（或关掉那个终端窗口 / 网页里「⚡ 服务」→ 关闭服务器） |
| 查看状态、打开了哪些页面 | `./start.sh status` |
| 直接打开某一页 | `./start.sh --page tools/metronome.html` |
| 没有页面打开 30 分钟后才自动退出 | `./start.sh --idle 30`（默认 10，0 = 不自动退出） |

如果双击后提示"无法打开"（例如文件夹是从网上下载或别人传过来的），在 `start.command` 上点右键 → 打开，确认一次即可。

本地服务只依赖 Python 3（macOS 自带），只监听本机 127.0.0.1。默认端口 8765，被占用时会自动换一个。**所有页面都关掉 10 分钟后，它会自己退出**，不会一直占着电脑。Windows 上运行 `python scripts\serve.py`。

**方式二：直接双击** `index.html`。大部分功能都能用，但部分浏览器在这种方式下不能用麦克风（调音器），也没法在网页里管理服务器。

配套工具（`tools/`）：🎹 在线钢琴 · ⏱️ 节拍器 · 👂 练耳训练 · 🎼 识谱练习 · 🥁 节奏练习 · 📖 和弦与音阶词典 · ⭕ 五度圈 · 🎶 和弦进行播放器 · 🎙️ 调音器

另有 ⚡ **服务管理**（`tools/services.html`）：统一查看、停止所有标签页里正在运行的工具和本地服务器。

## 服务：在文档里临时启动工具，用完就释放

- **临时打开**：教程正文里每个工具链接后面都有「⚡ 临时打开」小按钮。部分章节还有带预设的按钮，比如"⚡ 3/4 拍"、"⚡ Cm7"、"⚡ 卡农进行"。点一下，工具就会在右下角的浮动面板里打开，并按预设设好；不用离开当前页面。
- **面板**：可以同时开几个工具，比如节拍器和钢琴一起用，最多 3 个。点 `—` 收起时工具继续运行，点 `✕` 关闭时浏览器会回收它占用的全部资源。
- **⚡ 服务菜单**：在右上角，数字表示正在运行的服务个数（包括其他标签页）。点开可以逐个停止、一键全部停止，也能看到本地服务器的状态。
- **自动省资源**（可在「服务管理」里调整）：
  - 音频引擎：静音 30 秒后自动休眠，下次播放时自动唤醒。
  - 无人操作：30 分钟没有任何操作，就自动停止所有服务。
  - 麦克风：页面切到后台 1 分钟后自动关闭。
  - 本地服务器：所有页面关闭 10 分钟后自动退出。

## 小功能

- 侧栏记录学习进度（读完一章点"我学完这一章了"），首页显示"继续学习"。
- 顶栏搜索（按 <kbd>/</kbd> 聚焦）可搜索全站知识点。
- 右上角 🔊 可调整音量、音色（钢琴 / 电钢琴 / 风琴 / 吉他 / 纯音）和混响；🌙 切换深色模式。
- 每章末尾有小测验和"课后练一练"。

## 目录结构

```
music-theory/
├── start.command         macOS 双击启动（调用 start.sh）
├── start.sh              一键启动脚本：./start.sh [--bg | stop | status]
├── index.html            首页
├── chapters/             教程章节
├── tools/                配套工具 + services.html 服务管理
├── assets/css/style.css  全站样式
├── assets/js/            theory.js 乐理计算 · audio.js 合成器 · keyboard.js 键盘
│                         staff.js 五线谱 · jianpu.js 简谱 · site.js 站点框架与组件
│                         services.js 服务（面板、⚡ 菜单、跨标签页管理、服务器心跳）
├── scripts/              serve.py 本地服务 · make_launcher.sh 生成桌面图标 · 搜索索引、附录表格维护脚本
├── .run/                 运行时文件（服务器状态、日志、自动退出设置），可随时删除
├── .claude/launch.json   Claude 预览面板用的本地服务配置
├── .gitignore            上传到 GitHub 时忽略 .run/ 等本机文件
└── AUTHORING.md          开发与写作规范（组件用法、记谱语法、各章大纲）
```

## 维护

- 修改或新增章节后，重新生成搜索索引：`python3 scripts/build_search_index.py`
- 修改 `theory.js` 中的和弦/音阶定义后，重新生成附录表格：`python3 scripts/fill_appendix.py`
- 想新增内容？先读 [AUTHORING.md](AUTHORING.md)：只要写 HTML 加几个 `data-*` 属性，就能插入可播放的五线谱、简谱、键盘和测验。
