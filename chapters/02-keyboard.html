第 2 章

音名、唱名与键盘：给每个音起名字

上一章我们知道了：一个八度里有 12 个半音，而且每过一个八度就会"轮回"一次。这一章，我们给这些音起名字，并在钢琴键盘上一个一个找到它们。学完以后，不管面对多大的键盘，你都能一眼找到任意一个音。

⏱ 预计 20 分钟🎯 难度 ★☆☆☆☆🎹 边看边点键盘效果最好

学完本章，你将能够：

  • 说出七个基本音的三套叫法：音名（C D E…）、唱名（do re mi…）和简谱数字（1 2 3…）；
  • 利用黑键的"2 个一组、3 个一组"，在键盘上快速找到 C、F 以及任意白键；
  • 分清半音和全音，知道 E–F、B–C 是"天然的半音"；
  • 理解升号 ♯、降号 ♭、还原号 ♮，明白黑键为什么有两个名字；
  • 看懂 C4、A0 这样的写法，知道中央 C在哪里。

2.1 七个基本音：音名、唱名与简谱

一个八度里有 12 个音，其中有 7 个是最基本、最常用的——它们正好对应钢琴上的 7 个白键。这 7 个音，在中文的音乐学习里通常有三套叫法：

  • 音名note name：用英文字母 C D E F G A B 表示。它是每个音固定不变的名字，就像每个人的身份证号——不管在哪首曲子里，C 永远是 C。
  • 唱名solfège：do re mi fa sol la si，是唱歌时用的"昵称"。字母不好唱，换成这几个音节，张嘴就能唱出来。
  • 简谱数字：1 2 3 4 5 6 7，是在简谱（第 3 章会学）里书写用的。数字读出来时，就念对应的唱名：1 念 do，5 念 sol。

音名是循环使用的

弹到 B 之后，下一个白键叫什么？答案是——又回到 C。还记得第 1 章的"八度"吗？相差八度的音听起来"像同一个音"，所以它们共用同一个名字。七个音名就这样 C D E F G A B C D E… 一圈一圈地循环下去。

打个比方

音名就像一周的七天：星期一、星期二……星期日过完，又是新一周的星期一。C D E F G A B 是"一周"，B 后面接的是"下一周的 C"。至于是哪一周（哪个八度），我们在 2.5 节用数字来区分。

两个常见的小疑问

为什么字母从 C 开始，不从 A 开始？ 历史上字母确实是从 A 排起的，但今天最常用的"大调音阶"恰好从 C 开始、全部用白键（第 6 章会讲），所以大家习惯从 C 说起。

si 还是 ti？ 第七个唱名在中国大陆通常唱作 si，在英美国家常唱作 ti，两者是同一个音。本教程统一使用 si。

2.2 认识钢琴键盘

一架标准钢琴有 88 个键：52 个白键、36 个黑键。看起来密密麻麻，但其实它只是同一个"图案"的重复。仔细看黑键：它们总是 2 个一组、3 个一组，交替出现。

紫色是 C：每组"2 个黑键"左边的白键。橙色是 F：每组"3 个黑键"左边的白键。

这个"2 + 3"的图案每 12 个键（7 白 + 5 黑）重复一次，正好是一个八度。所以只要找到图案，就能找到任何音：

  1. 找 C：先找到"2 个黑键"的那一组，紧挨着它左边的白键就是 C。
  2. 找 F：找到"3 个黑键"的那一组，紧挨着它左边的白键就是 F。
  3. 其他白键：从 C 往右依次是 D E F G A B，从 F 往右依次是 G A B C……
记忆口诀

"两黑左边是 C，三黑左边是 F。"
还有几个好记的位置：D 夹在 2 个黑键的正中间；G 和 A 夹在 3 个黑键的中间（G 在左、A 在右）；E 和 B 都在一组黑键的右边。

小游戏：找一找
点击"开始"，然后在键盘上点出所有的目标音。

2.3 半音与全音

第 1 章说过，钢琴上相邻的两个键相差一个半音semitone / half step——这里的"相邻"包括黑键：白键和它旁边的黑键是相邻的，黑键和它旁边的白键也是相邻的。两个半音合在一起，叫作一个全音whole tone / whole step。

  • 半音 = 相邻的两个键，中间没有别的键。例如 C 和它右边的黑键。
  • 全音 = 中间隔着一个键。例如 C 和 D（中间隔着一个黑键）。
注意紫色的 E–F 和 B–C：它们之间没有黑键，是紧挨着的两个白键，所以只相差一个半音。

这就是键盘上黑键"有缺口"的原因：大多数相邻的白键之间隔着一个黑键（相差全音），唯独 E–F 和 B–C 之间没有黑键，它们是天然的半音。把七个白键之间的距离排成一行，就是：

C全D全E半F全G全A全B半C
C 到高音 C 的七步：全、全、半、全、全、全、半。这串"密码"在第 6 章学大调音阶时会再次出现，现在先混个眼熟。
常见误区

"相邻的白键一定相差全音"——错！E–F、B–C 也是相邻的白键，却只差半音。判断半音还是全音，要看两个键之间还有没有别的键（包括黑键），而不是看颜色。

2.4 变音记号：升号、降号与还原号

白键有了名字，那 5 个黑键叫什么呢？黑键没有自己的字母，而是"借用"旁边白键的名字，再加上一个变音记号accidental：

♯ 升号 sharp

把音升高一个半音，也就是往右移一个键。
C♯ 读作"升 C"：C 右边紧挨着的黑键。

♭ 降号 flat

把音降低一个半音，也就是往左移一个键。
D♭ 读作"降 D"：D 左边紧挨着的黑键。

♮ 还原号 natural

取消前面的升号或降号，回到原来的音。
在乐谱里常用来"撤销"升降。

你可能已经发现了：C 右边的黑键是 C♯，而 D 左边的黑键是 D♭——它们是同一个键！这种"音高相同、名字不同"的关系叫作等音enharmonic。所以每个黑键都有两个名字：

每个黑键上都写着它的两个名字：上面是升号写法，下面是降号写法。
黑键的位置升号名降号名读作试听
C 和 D 之间C♯D♭升 C ／ 降 D
D 和 E 之间D♯E♭升 D ／ 降 E
F 和 G 之间F♯G♭升 F ／ 降 G
G 和 A 之间G♯A♭升 G ／ 降 A
A 和 B 之间A♯B♭升 A ／ 降 B

那该叫 C♯ 还是 D♭ 呢？这取决于音乐的上下文（比如所在的调），第 6 章学调号时自然就明白了。现在只要记住：它们是同一个键，弹出来的声音完全一样。

白键也可以升降

升号、降号的意思是"升高/降低一个半音"，并没有规定结果一定是黑键。因为 E–F、B–C 之间没有黑键，所以会出现这样的等音：

  • E♯ = F，F♭ = E
  • B♯ = C，C♭ = B

这些写法在入门阶段比较少见，但在某些调里一定会遇到，先知道"有这回事"就好。另外还有把音升高两个半音的重升号 𝄪、降低两个半音的重降号 𝄫（比如 F𝄪 其实就是 G 那个键），更是少见，了解即可。

常见误区

"升号 = 黑键"——不对。升降号表示的是"升高/降低一个半音"这个动作，E♯ 就是一个白键（F 那个键）。同样，黑键也不一定非得叫升号名，它也可以叫降号名。

在乐谱里：变音记号写在音符左边

说的时候我们把升降号放在字母后面（C♯ 读"升 C"），但在五线谱上，变音记号写在音符的左边。还有一个重要规则：谱中临时出现的变音记号，从出现的位置开始，一直管到这一小节结束；过了小节线就失效了。看下面的例子（小节线和五线谱在下一章细讲）：

① 写了升号 → F♯；② 同一小节内，不用再写，仍然是 F♯；③ 还原号取消升号 → F；④ 想再升高必须重新写升号；⑤ 过了小节线，升号失效 → F；⑥ 重新写升号 → F♯。

2.5 音区与八度编号：C4 是哪个 C？

同一个音名在键盘上会出现好多次（每个八度一次）。要准确地说出"是哪一个 C"，就需要给八度编号。全世界最常用的方法叫科学音高记号scientific pitch notation：音名 + 八度编号，比如 C4、A4、G2。

  • 钢琴最中间附近的那个 C 叫中央 Cmiddle C，记作 C4。它通常就在钢琴品牌标志的正下方附近。
  • 第 1 章的标准音 A = 440 Hz，就是中央 C 右边的第一个 A：A4。
  • 88 键钢琴最左边的键是 A0，最右边的键是 C8。
点任意一个键这里会显示它的名字、序号和频率。键盘可以左右滑动。
完整的 88 键钢琴。紫色是中央 C（C4），橙色是标准音 A4。
最容易出错的地方：编号在 C 处才增加

八度编号是从 C 开始换号的：从 C4 往右依次是 C4、D4、E4、F4、G4、A4、B4，下一个键才是 C5。所以 B3 右边紧挨着的白键是 C4（不是 C3），A4 比 C4 高、而 A3 比 C4 低。

国内教材的"音组"叫法

在国内的音乐课本和考级教材里，你还会看到另一套叫法：把每个八度叫作一个音组，用大小写字母和上下角标来区分。它和科学音高记号的对应关系如下：

大字二组A₂ B₂A0 B0最左边的 3 个键
大字一组C₁ ～ B₁C1 ～ B1
大字组C ～ BC2 ～ B2
小字组c ～ bC3 ～ B3中央 C 左边的一组
小字一组c¹ ～ b¹C4 ～ B4中央 C = c¹，标准音 a¹ = 440 Hz
小字二组c² ～ b²C5 ～ B5
小字三组c³ ～ b³C6 ～ B6
小字四组c⁴ ～ b⁴C7 ～ B7
小字五组c⁵C8最右边的 1 个键

两套方法都是在说"哪一个八度的哪个音"，只是写法不同。本教程统一使用更通用的科学音高记号（C4、A4……），遇到 c¹、a¹ 时，对照上表换算即可。

本章小结

要点回顾
  • 七个基本音有三套叫法：音名 C D E F G A B、唱名 do re mi fa sol la si、简谱 1 2 3 4 5 6 7；音名循环使用，B 之后又是 C。
  • 钢琴黑键 2 个一组、3 个一组：两黑左边是 C，三黑左边是 F。
  • 相邻两个键相差半音，隔一个键是全音；E–F、B–C 之间没有黑键，是天然的半音。白键之间的距离是"全全半全全全半"。
  • ♯ 升高半音，♭ 降低半音，♮ 还原。黑键有两个名字（如 C♯ = D♭），叫作等音；白键也有等音（E♯ = F、C♭ = B）。
  • 谱中的临时变音记号管到本小节结束。
  • 科学音高记号：中央 C = C4，A4 = 440 Hz，八度编号在 C 处换号；国内教材中中央 C 写作 c¹（小字一组）。

  2. D
  3. C
  4. B

  1. C – D
  2. E – F
  3. G – A
  4. A – B
E–F 之间没有黑键，是相邻的两个键，相差半音；其余三对中间都隔着一个黑键，相差全音。

C♯ 和 D♭ 是什么关系？

  1. 相差一个半音
  2. 同一个键，名字不同（等音）
  3. 相差一个全音
  4. 相差一个八度
C 升高半音、D 降低半音，都落在 C 和 D 之间的那个黑键上——音高完全相同，这叫等音。

  1. 全音
  2. 半音
  3. 八度
这是 C4 → D4，中间隔着一个黑键（C♯），相差全音（两个半音）。对比一下 ，半音听起来"挨得更近"。
