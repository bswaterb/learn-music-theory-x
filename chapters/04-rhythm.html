第 4 章

节奏与节拍：音乐的心跳

前几章我们一直在研究"音有多高"。从这一章开始，我们来研究"音有多长"——也就是音乐的时间。拍子、速度、音符的长短、休止、拍号……学完这一章，你就能跟着节拍器，把谱上的节奏准确地拍出来。

⏱ 预计 30 分钟🎯 难度 ★★☆☆☆👏 准备好双手，边学边拍

学完本章，你将能够：

  • 理解什么是拍子和速度（BPM），认识常见的速度术语；
  • 认识全音符到十六分音符、以及对应的休止符，并算出它们各占几拍；
  • 读懂附点和延音线；
  • 看懂拍号，听出 2/4、3/4、4/4、6/8 拍的强弱规律；
  • 认识弱起、切分音、三连音，能跟着节拍器拍出简单的节奏。

4.1 拍子与速度

听歌的时候，你是不是会不由自主地跟着点头、拍腿或者踩脚？你跟着的那个稳定、均匀、一直持续的"咚、咚、咚"，就是拍子（beat），也简称"拍"。它就像音乐的心跳。

拍子有两个特点：

  • 均匀：每一拍之间的距离一样长，不会忽快忽慢；
  • 持续：哪怕某一刻没有声音（比如休止），拍子也在心里继续走。
打个比方：刻度与线段

拍子就像尺子上的刻度，均匀地排开；节奏则是你在尺子上画的长长短短的线段。线段可以长、可以短、中间还可以留空，但刻度永远是均匀的。所以我们常说：拍子是"格子"，节奏是往格子里放的东西。

速度：BPM

拍子有快有慢。拍子的快慢叫速度（tempo），通常用 BPM（Beats Per Minute，每分钟多少拍）来表示：

  • 60 BPM：每秒正好 1 拍，和钟表的秒针一样；
  • 120 BPM：每秒 2 拍，像快步走路；
  • 换算公式：每拍的秒数 = 60 ÷ BPM。

乐谱开头常常写着"♩ = 90"，意思就是"每分钟 90 个四分音符"，即 90 BPM。下面是一个小节拍器，先用 60 BPM 听一听，再拖动滑块，感受速度的变化：

4.2 音符的时值

拍子是"格子"，而音符告诉我们每个音要占几个格子。一个音持续的长短，叫作它的时值（duration）——第 1 章讲过，它是乐音的四个属性之一。

音符长什么样

一个音符最多由四部分组成：

符头（实心或空心）+ 符干 + 符尾（小旗子）。几个八分、十六分音符挨在一起时，常用"符杠"代替符尾把它们连起来。
  • 符头：椭圆形的"头"，有空心和实心两种。它在五线谱上的上下位置表示音高（第 3 章），它的样子和符干、符尾一起表示时值。
  • 符干：竖直的细线。符干朝上时画在符头右边，朝下时画在左边——方向只是为了排版好看，不影响时值。
  • 符尾：符干末端的小旗子。每多一条符尾，时值就减少一半。
  • 符杠：几个带符尾的音符挨在一起时，用粗横杠把它们连成一组，通常一拍连一组，让人一眼看出拍子在哪里。

音符家族树

在最常见的情况下，我们以四分音符为一拍。下面这棵"家族树"从上往下看：每往下一层，音符的个数翻一倍，每个音符的时值减一半——就像把一块蛋糕不断地对半切。每一层加起来都是 4 拍。

记忆口诀

"空心长，实心短；尾巴越多跑得越快。"

1 个全音符 = 2 个二分音符 = 4 个四分音符 = 8 个八分音符 = 16 个十六分音符。

简谱里的时值

简谱用两种短横线表示时值（第 3 章已经见过）：

  • 增时线：写在数字右边的短横"-"，每一条让前面的音多一拍。1 - 是 2 拍，1 - - - 是 4 拍。
  • 减时线：写在数字下面的横线，每一条让时值减半。一条是八分音符（½ 拍），两条是十六分音符（¼ 拍）。
和上面的家族树一一对应：全音符、二分音符、四分音符、八分音符、十六分音符，每小节都是 4 拍。

4.3 休止符

音乐里的"安静"也是有长度的。表示"这里不发声、要停多久"的记号叫休止符（rest）。每一种音符都有一个对应的休止符，时值完全一样，只是不发声。

五种休止符。第二小节加起来正好也是 4 拍：2 + 1 + ½ + ¼ + ¼ = 4。

全休止符"挂"在第四线下面的小黑块4 拍（也常用来表示"整小节休止"）0 0 0 0
二分休止符"坐"在第三线上面的小黑块2 拍0 0
四分休止符像一道弯弯曲曲的闪电1 拍0
八分休止符一个小圆点 + 一条斜线，像数字"7"½ 拍0 下面 1 条横线
十六分休止符两个小圆点 + 斜线¼ 拍0 下面 2 条横线
全休止和二分休止怎么分？

它们长得几乎一样，区别只在位置：全休止符"挂"在线下，像挂在衣钩上的厚大衣——又重又长（4 拍）；二分休止符"坐"在线上，像放在桌上的帽子——轻一些、短一些（2 拍）。

来听一段带休止的旋律。注意：休止的时候节拍器还在"嗒嗒"地走——休止不是停下来，而是安静地数拍。

简谱里的休止

简谱用 0 表示休止。注意：休止不用增时线延长，休息两拍要写成 0 0，休息四拍写成 0 0 0 0。

小贴士

遇到休止符时，最容易犯的错是"抢拍"——还没数够就急着进下一个音。可以在休止的地方轻轻点头或者小声数出来，帮自己把拍子数满。

4.4 附点与延音线

只用上面五种音符，能写出的时值只有 4、2、1、½、¼ 拍。那如果想要一个 3 拍的音、或者 1 拍半的音怎么办？这就需要附点和延音线。

附点：再加一半

写在符头右边的小圆点叫附点。附点让音符的时值增加原来的一半，也就是变成原来的 1.5 倍：

附点音符计算时值简谱写法
附点二分音符2 + 13 拍1 - -
附点四分音符1 + ½1½ 拍1.
附点八分音符½ + ¼¾ 拍1. 下面一条横线

最常见的附点组合是"附点四分音符 + 八分音符"，两个加起来正好 2 拍，听起来是"长——短"（哒——哒）。你一定听过：贝多芬《欢乐颂》第一句的结尾就是它（标橙色的两个音）：

延音线：把两个音连成一个

延音线（tie）是连接两个相同音高音符的弧线。被连起来的音只弹（唱）第一个，第二个不再重新发声，时值直接加到第一个上。

它主要有两个用处：一是让一个长音跨过小节线；二是写出单个音符写不出来的时值（比如 5 拍 = 全音符 + 四分音符）。对比下面两个例子，最后的 C 有什么不同：

延音线 vs. 圆滑线

乐谱上还有一种长得很像的弧线，叫圆滑线（slur）。区别很简单：

  • 延音线连接的是同一个音高（同一高度的两个音），作用是"时值相加、只弹一次"；
  • 圆滑线连接的是不同的音高，作用是"连贯地演奏"，每个音都要弹，只是音与音之间不断开（第 9 章详细讲）。
常见误区：附点 ≠ 跳音

附点写在符头的右边，表示时值加一半；而写在符头正上方或正下方的小圆点叫"跳音"，意思是弹得短促（第 9 章）。两者位置不同、意思完全不同。

4.5 拍号与小节

如果一首歌从头到尾都是均匀的"嗒嗒嗒嗒"，读谱的人很容易数乱。所以人们把拍子分组：每几拍为一组，叫作一个小节（measure / bar），小节之间用竖线隔开，这条竖线就是小节线。乐曲结束处用一细一粗的终止线，段落之间常用两条细线的双纵线。

拍号：上面几拍，下面谁是一拍

每小节有几拍、以什么音符为一拍，由写在乐谱开头的拍号（time signature）规定。拍号是上下两个数字：

  • 上面的数字：每小节有几拍；
  • 下面的数字：以几分音符为一拍（4 表示四分音符，8 表示八分音符，2 表示二分音符）。

比如 3/4 拍（读作"四三拍"或"四分之三拍"）就是"以四分音符为一拍，每小节 3 拍"。4/4 拍也常写成一个大写的 C，叫"普通拍子"（common time）。

拍号口诀

"上面数几拍，下面看谁是一拍。"拍号虽然长得像分数，但不能约分：2/4 和 4/8、3/4 和 6/8 都是不同的拍子。

强弱规律

同一小节里的几拍并不一样"重"。第一拍通常最强，叫强拍；其他拍较轻，叫弱拍；有的拍号里还有一个次强拍。这种有规律的轻重循环，就是让我们"感觉到"拍子的秘密。选一个拍号，听听它的强弱：

大圆 = 强拍（高而响的"嗒"），中圆 = 次强拍，小圆 = 弱拍。
拍号含义强弱规律常见于
2/4四分音符为一拍，每小节 2 拍强 弱进行曲、节奏明快的儿歌
3/4四分音符为一拍，每小节 3 拍强 弱 弱圆舞曲（华尔兹）、《生日快乐》
4/4（C）四分音符为一拍，每小节 4 拍强 弱 次强 弱绝大多数流行歌曲、儿歌

2/4、3/4 每小节只有一个强拍，叫单拍子；4/4、6/8 是由两个单拍子组合起来的，有强拍也有次强拍，叫复拍子。另外还有 5/4、7/8 这样由不同单拍子混合而成的混合拍子，在一些民族音乐和电影音乐里能听到，入门阶段了解即可。

圆舞曲的伴奏通常是：第一拍弹一个低音（强），后两拍弹两下和弦（弱）。打开节拍器听，是不是有了转圈跳舞的感觉？

6/8 拍：三个八分音符一组

6/8 拍以八分音符为一拍，每小节 6 拍，但我们通常把它感觉成两大拍：每 3 个八分音符为一组（正好是一个附点四分音符的长度），"强弱弱 次强弱弱"，像摇篮一样左右摇摆。

3/4 和 6/8 不一样！

3/4 和 6/8 每小节都等于 6 个八分音符的长度，但分组完全不同：3/4 是 3 组 × 2 个（强 弱 弱），6/8 是 2 组 × 3 个（强弱弱 次强弱弱）。看看符杠的连法，再听听节拍器的重音：

4.6 弱起、切分与三连音

掌握了强弱规律，我们就可以来认识三种"打破常规"的节奏了。它们让音乐更有趣、更有动感。

弱起：从弱拍开始

不是所有的歌都从第一拍（强拍）开始。如果乐曲从弱拍开始，第一小节就是不完整的，这样的小节叫弱起小节（pickup / anacrusis）。最熟悉的例子就是《生日快乐》——它是 3/4 拍，开头的两个音落在第 3 拍（弱拍）上，后面的"6"才是第一个强拍：

弱起小节的规矩

有弱起的乐曲，最后一小节通常也不完整，而且"弱起小节 + 最后一小节"的拍数正好凑成一个完整的小节。上面的例子里，弱起是 1 拍，最后一小节是 2 拍，加起来正好是 3/4 拍的 3 拍。数小节时，弱起小节不算第 1 小节。

切分音：重音"挪了位置"

正常情况下，重音落在强拍上。如果一个音从弱拍（或一拍的后半拍）开始，并一直延续到下一个强位置，原本的强弱关系就被"切开"了，这样的音叫切分音（syncopation）。最典型的是"八分—四分—八分"：

4.7 节奏练习

节奏是"练"出来的，不是"看"出来的。下面有 8 条由易到难的节奏练习，都写在单线节奏谱上（只关心长短，不关心音高）。建议按这个方法练：

  1. 先看：数清每小节的拍数，找出每个音落在哪一拍上。下方的数字就是它开始的位置："+"表示前一拍的后半拍，"(2)+"表示第 2 拍被前面的长音占住了、这个音从第 2 拍的后半拍开始。
  2. 念出来：脚轻轻踩拍子，嘴里用"哒"把节奏念出来，长音就拖长。
  3. 拍出来：开着节拍器，用手拍节奏。
  4. 对照：点"播放"听标准答案（会先给一小节预备拍），哪里不一样就回去重练那一小节。

本章小结

要点回顾
  • 拍子是音乐中均匀持续的脉搏；速度用 BPM 表示，60 BPM = 每秒一拍。
  • 以四分音符为一拍时：全音符 4 拍、二分 2 拍、四分 1 拍、八分 ½ 拍、十六分 ¼ 拍；每种音符都有时值相同的休止符。
  • 附点让时值增加一半；延音线连接相同音高，时值相加、只弹一次（不要和圆滑线混淆）。
  • 拍号：上面数字 = 每小节几拍，下面数字 = 以几分音符为一拍。强弱规律：2/4 强弱、3/4 强弱弱、4/4 强弱次强弱、6/8 强弱弱次强弱弱。
  • 弱起从弱拍开始；切分音让重音落到弱位置；三连音把一拍平均分成三份。

小测验

以四分音符为一拍时，一个全音符等于几拍？

  1. 1 拍
  2. 2 拍
  3. 4 拍
  4. 8 拍
全音符 = 2 个二分音符 = 4 个四分音符，所以是 4 拍。

附点二分音符是几拍？

  1. 2 拍
  2. 2½ 拍
  3. 3 拍
  4. 4 拍
附点让时值增加原来的一半：二分音符 2 拍 + 一半（1 拍）= 3 拍。

拍号 3/4 表示什么？

  1. 以四分音符为一拍，每小节 3 拍
  2. 以三分音符为一拍，每小节 4 拍
  3. 每小节 3 个四分音符加 4 个八分音符
  4. 速度是每分钟 34 拍
"上面数几拍，下面看谁是一拍"：上面 3 = 每小节 3 拍，下面 4 = 以四分音符为一拍。

4/4 拍的强弱规律是？

  1. 强 弱 强 弱
  2. 强 弱 次强 弱
  3. 强 弱 弱 弱
  4. 弱 强 弱 强
4/4 拍是复拍子，由两个 2/4 组合而成：第 1 拍强，第 3 拍次强，第 2、4 拍弱。

听一听： 这段节奏是哪一个？

  1. ♩ ♩ ♩ ♩（四个四分音符）
  2. ♫ ♩ ♫ ♩（八分八分 四分 八分八分 四分）
  3. ♩. ♪ ♩ ♩（附点四分 八分 四分 四分）
每一组都是"两个快的 + 一个慢的"：两个八分音符（共 1 拍）+ 一个四分音符（1 拍），重复两次，答案是 ♫ ♩ ♫ ♩。

关于延音线，下面哪个说法正确？

  1. 它连接两个不同的音，表示连贯演奏
  2. 它表示音符的时值增加一半
  3. 它连接两个相同音高的音，时值相加、只弹一次
  4. 它表示这个音要弹得短促
延音线连接同一个音高，第二个音不重新弹，时值直接加到第一个上。A 说的是圆滑线，B 说的是附点，D 说的是跳音。
