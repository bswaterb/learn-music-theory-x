第 7 章

和弦：同时响起的几个音

前面几章，我们听的大多是"一个接一个"出现的音。当三个或更多的音同时响起，就构成了和弦。吉他弹唱、钢琴伴奏、乐队编曲，几乎都建立在和弦之上。学完这一章，你就能看懂 C、Am、G7、Cmaj7 这样的和弦名，并能在键盘上把它们弹出来。

⏱ 预计 30 分钟🎯 难度 ★★★☆☆📚 建议先学：第 5 章 音程、第 6 章 音阶与调

学完本章，你将能够：

  • 说出什么是和弦、什么是"三度叠置"，认识根音、三音、五音；
  • 区分并听辨大三、小三、减三、增三四种三和弦；
  • 看懂和弦符号（C、Cm、C°、C+、G7、Cmaj7……）和罗马数字级数（I、IV、V、vi……）；
  • 理解和弦转位和斜线和弦（如 C/E），知道为什么要用转位；
  • 写出任意大调的七个调内和弦，记住口诀"大小小大大小减"。

7.1 什么是和弦

第 5 章我们学过：两个音同时响起，叫作"和声音程"。如果同时响起的是三个或更多音名不同的音，它就叫和弦Chord。

三度叠置：隔一个音取一个

和弦并不是随便按几个键。最常见的和弦都是用三度叠置的方法搭起来的：从一个音出发，隔一个音名取一个音，像叠积木一样，一层一层往上叠三度。

CDEFG →C – E – G
在白键上"隔一个取一个"：C、（跳过 D）E、（跳过 F）G。相邻两个音都相距一个三度。

根音、三音、五音

和弦里的每个音都有自己的"职务"：

  • 根音Root，简写 R：最下面的"地基"，和弦以它命名。C–E–G 的根音是 C，所以叫"C 和弦"。
  • 三音3rd：根音上方三度的音（这里是 E）。它决定和弦是"明亮"还是"忧伤"（下一节详细讲）。
  • 五音5th：根音上方五度的音（这里是 G）。它让和弦更饱满、更稳。
打个比方

和弦像一个三口之家：根音是户主，决定这家"姓什么"；三音决定这家人的性格是开朗还是内向；五音让这个家更稳固、更完整。

在五线谱上，三度叠置的和弦特别好认：它像一串糖葫芦，三个音要么全在线上，要么全在间里，一个挨一个地"摞"起来。

你会发现：有的听起来明亮（C、F、G 开头的），有的有点忧伤（D、E、A 开头的），而 B–D–F 特别紧张。明明都是"隔一个取一个"，为什么表情不同？下一节揭晓。

音可以重复，也可以换八度

只要组成音的音名不变，和弦的名字就不变。比如 C–E–G–C（多加一个高八度的 C）仍然是 C 和弦。吉他上最常见的 C 和弦其实有 5 个音：C–E–G–C–E。

7.2 四种三和弦

由根音、三音、五音这三个音组成的和弦，叫三和弦Triad。回忆第 5 章：三度有大有小——大三度 = 4 个半音，小三度 = 3 个半音。三和弦由两个三度摞成，两个三度"一大一小"地组合，正好有四种可能：

记忆口诀

从下往上看两个三度："大小"是大三，"小大"是小三，"小小"是减三，"大大"是增三。

还可以这样记：大三和弦和小三和弦只差一个音——把大三和弦的三音降低半音，就变成了小三和弦。

现在你就能解释上一节的"七个白键和弦"了：C–E–G、F–A–C、G–B–D 是大三和弦；D–F–A、E–G–B、A–C–E 是小三和弦；B–D–F 两个都是小三度，是减三和弦——它的根音和五音相距"减五度"（6 个半音，也就是第 5 章的"三全音"），所以格外紧张。

常见误区
  • "小三和弦"的"小"，说的是根音到三音是小三度，不是说这个和弦"小"或"不重要"。流行歌曲里小三和弦和大三和弦一样常用。

7.3 和弦的名字怎么写

和弦符号

流行歌曲的吉他谱、钢琴谱上，常在旋律上方写着 C、Am、G7 这样的字母，这叫和弦符号Chord symbol。规则很简单：根音的音名 + 表示类型的后缀。

写法含义组成音试听
C只写字母 = 大三和弦C E G
Cm小三和弦，m 是 minor（小）的缩写；也写作 Cmin、C−C E♭ G
Cdim / C°减三和弦，dim 是 diminished（减）的缩写C E♭ G♭
Caug / C+增三和弦，aug 是 augmented（增）的缩写C E G♯
F♯m根音带升降号时，写在字母后面：升 F 小三和弦F♯ A C♯
B♭降 B 大三和弦B♭ D F
小心大小写

小写 m = minor（小）；大写 M 或 maj = major（大）。Cm7 和 CM7 只差一个字母的大小写，却是完全不同的两个和弦（7.4 节会讲）。看谱时一定要看清楚！

罗马数字级数

和弦符号告诉你"弹哪几个音"。但分析音乐时，人们更关心这个和弦在调里排第几：它的根音是音阶的第几个音？这就是级数，用罗马数字表示。

罗马数字IIIIIIIVVVIVII
对应的音阶级数1234567
C 大调中的根音CDEFGAB

罗马数字的大小写还顺便告诉你和弦的类型：

  • 大写（I、IV、V）= 大三和弦；
  • 小写（ii、iii、vi）= 小三和弦；
  • 小写 + °（vii°）= 减三和弦；大写 + +（III+）= 增三和弦。

所以在 C 大调里，I = C、ii = Dm、IV = F、V = G、vi = Am（为什么是这样，7.6 节揭晓）。

级数的好处：换调不换"味道"

"I–IV–V–I"在 C 大调里是 C–F–G–C，在 G 大调里是 G–C–D–G。音高变了，但听起来是同一个"故事"：

流行音乐圈常说的"1645""4536"，就是把级数写成阿拉伯数字的简称（第 8 章会大量用到）。

7.4 七和弦

在三和弦上面再叠一个三度，就得到四个音：根音、三音、五音、七音。最上面的音和根音相距七度，所以叫七和弦Seventh chord。七和弦比三和弦更丰富、更有"味道"，爵士、R&B、抒情流行里到处都是它。

七和弦的名字可以这样理解：七和弦 = 一个三和弦 + 一个七度。最常见的五种（以 C 为根音）：

关于 B𝄫（重降 B）

减七和弦的七音比"小七度"再低半音，从 C 往上数正好是一个"减七度"，按音名必须写成 B𝄫（重降 B）。在键盘上它就是 A 键。减七和弦里每两个相邻的音都是小三度，正好把一个八度平均分成了 4 份，所以听起来格外"悬"。

只写一个 7，就是属七

C7 = C E G B♭（小七度），而不是 C E G B。想表示大七度，必须写 maj7（或 M7、Δ7）。记住："7"默认就是"小七度"。

属七和弦：想"回家"的和弦

五种七和弦里最重要的是属七和弦。在 C 大调里，它长在第 5 级（"属音"G）上：G7 = G B D F——这也是它叫"属七"的原因。

G7 里的 B 和 F 构成一个"三全音"（第 5 章），非常不稳定：B 想往上走半音到 C，F 想往下走半音到 E。它们一起"落地"，就回到了 C 和弦，带来强烈的"到家了"的感觉。

听最后一个按钮：只弹 G7 就停下，是不是觉得"话没说完"、很想再听一个 C？这种"紧张→解决"的力量，正是和弦进行的核心，第 8 章会详细讲。

7.5 和弦转位

到目前为止，和弦的根音都在最下面，这叫原位和弦。但实际演奏时，最下面的音——也就是低音Bass——不一定是根音。只要组成音不变，把它们的上下顺序换一换，和弦的名字（根音）不变，但"站姿"变了，这就是转位Inversion。

转位谁在最下面C 和弦的排列（从下往上）写法
原位根音C E GC
第一转位三音E G CC/E
第二转位五音G C EC/G
第三转位（只有七和弦才有）七音F G B D（G7）G7/F

怎么得到转位？很简单：把最下面的那个音搬到最上面（升高一个八度）。搬一次是第一转位，搬两次是第二转位。

打个比方

转位就像一家三口拍照换了站位：人还是那三个人，这家还是姓"C"，只是谁站在最前面（最下面）不一样了。

斜线和弦

和弦符号里的斜线专门用来表示转位：C/E 读作"C over E"，斜线左边是和弦，右边是低音。C/E 就是"弹 C 和弦，但让 E 在最下面"。

进阶一点：斜线右边的低音也可以不是和弦里的音，比如 C/D。这类用法以后遇到再学，入门阶段知道"斜线右边 = 低音"就够了。

为什么要转位？

理由一：让低音线条更平滑。原位和弦的低音总在根音上，常常跳来跳去；用上转位，低音可以像走楼梯一样一级一级地走。对比下面两段，和弦完全一样，只是低音不同：

A. 全部用原位：低音 C – G – A – E – F，跳来跳去

B. 用上转位：低音 C – B – A – G – F，一级一级往下走

两段的和弦完全相同（C、G、Am、Em、F），右手部分也一样，只有低音不同。

B 段的低音 C–B–A–G–F 像下楼梯一样平稳，这种"下行低音"在流行歌和古典音乐里都非常常见。

理由二：弹起来更省力。钢琴上用原位弹 C → F → G，整只手要跟着跳；换成 C → F/C → G/B，手几乎不用移动，只要动一两个手指：

7.6 调内和弦

回忆第 6 章：C 大调由 C D E F G A B 七个音组成。如果只用这七个音，在每个音上都"隔一个取一个"叠一个三和弦，就得到 7 个和弦。它们叫调内和弦Diatonic chords，也叫"顺阶和弦"。一首 C 大调的歌，用到的大部分和弦都在这里面。

级数IiiiiiIVVvivii°
C 大调CDmEmFGAmB°
性质大小小大大小减
口诀：大小小，大大小减

大调的 7 个调内三和弦，性质永远是"大、小、小、大、大、小、减"（I 大、ii 小、iii 小、IV 大、V 大、vi 小、vii° 减）。不管是 C 大调、G 大调还是 B♭ 大调，这个排列都一样！

为什么？因为每个大调音阶的"全全半全全全半"结构都一样，两个半音（3→4、7→1）总落在相同的位置，叠出来的三度大小也就一样。

别混淆
  • Cadd9（C E G D）没有七音；C9 则是在 C7 上再加九度（C E G B♭ D），包含 ♭7。

C9、C13、C7♭9、Cm(maj7)……和弦符号可以写得很复杂。别担心：入门阶段，本章的三和弦、五种七和弦，加上 sus、add9、6，已经足够应付绝大多数流行歌曲的和弦谱了。遇到不认识的，可以去 📖 和弦与音阶词典 查一查。

本章小结

要点回顾
  • 三个或以上的音同时发声叫和弦；最常见的和弦用三度叠置（隔一个音取一个）搭成，由根音、三音、五音组成。
  • 四种三和弦：大三（大+小，明亮）、小三（小+大，忧伤）、减三（小+小，紧张）、增三（大+大，悬疑）。
  • 和弦符号 = 根音 + 后缀：C、Cm、Cdim（C°）、Caug（C+）；罗马数字表示和弦在调里的级数，大写为大三、小写为小三。
  • 七和弦 = 三和弦 + 七度：maj7、7（属七）、m7、m7♭5、dim7。只写"7"就是属七，属七和弦强烈地想"回家"（G7 → C）。
  • 转位改变的是最下面的音：原位、第一转位（C/E）、第二转位（C/G）。转位让低音更平滑、演奏更省力。
  • 大调调内和弦口诀：大小小，大大小减。I、IV、V 是主要三和弦，包含音阶的全部 7 个音。

  3. A C E♭
  4. A B E
m 表示小三和弦：根音 A，上方小三度 C，纯五度 E，所以是 A C E。A C♯ E 是 A 大三和弦。

按照"大小小，大大小减"，大调的 V 级和弦是什么性质？在 G 大调中它是哪个和弦？

  1. 大三和弦，D
  2. 小三和弦，Dm
  3. 大三和弦，C
  4. 减三和弦，F♯°
V 级是第 5 个，口诀里排第 5 的是"大"。G 大调音阶 G A B C D E F♯，第 5 个音是 D，所以 V 级是 D 大三和弦（D F♯ A）。

C/E 表示什么？

  1. C 和弦，低音是 E（第一转位）
  2. C 和弦和 E 和弦同时弹
  3. C 和弦与 E 和弦交替弹
  4. E 小三和弦
斜线左边是和弦，右边是低音。C/E 就是 C 和弦让三音 E 在最下面，即第一转位。

下面哪一组是 G7 的组成音？

  1. G B D F♯
  2. G B♭ D F
  3. G B D F
  4. G B D E
只写"7"就是属七和弦：大三和弦 G B D + 小七度 F，即 G B D F。G B D F♯ 是 Gmaj7，G B♭ D F 是 Gm7，G B D E 是 G6。
