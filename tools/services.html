    一键启动脚本

    项目根目录里有两个启动脚本，都只依赖 macOS 自带的 Python 3。服务只监听本机（127.0.0.1），别的电脑访问不到。

    想做什么在「访达」里在终端里（项目目录下）
    启动并打开网站双击 start.command./start.sh
    后台启动，不占终端窗口—./start.sh --bg
    停止关掉那个终端窗口，或本页「关闭服务器」./start.sh stop
    查看状态、打开了哪些页面本页./start.sh status
    直接打开某一页—./start.sh --page tools/metronome.html
    改自动退出时间本页「本地服务器」设置./start.sh --idle 30（0 = 不自动退出）

    已经在运行时再次启动，不会开第二个，而是直接打开浏览器；默认端口 8765 被别的程序占用时会自动换一个。Windows 可以运行 python scripts\serve.py。

    这些"服务"分别占用什么

    服务占用什么时候自动停
    🖥️ 本地服务器一个很小的 Python 进程，空闲时几乎不占 CPU所有页面关闭后，等设定的时间（默认 10 分钟）自动退出
    🔊 音频引擎浏览器的音频线程，运行时一直占一点 CPU没有声音 30 秒后自动休眠，播放时自动唤醒
    ▶️ 正在播放节拍器、伴奏、乐谱播放等，持续调度声音你点停止；或 30 分钟没有任何操作
    🎙️ 麦克风麦克风 + 每秒约 30 次音高分析页面切到后台 1 分钟；或 30 分钟没有任何操作
    🧩 面板里的工具一个嵌入的工具页（有自己的脚本和音频）点 ✕ 立即释放；最多同时开 3 个，再开会自动关掉最久没用的空闲面板

    所有工具都在浏览器里运行，真正的后台进程只有本地服务器一个；而上面这些自动停止规则，保证不用时不会一直占着电脑。

    常见问题

    不启动服务器能用吗？能。直接双击 index.html 也可以学习，只是部分浏览器里麦克风（调音器）不可用，也没法在这里管理服务器。

    关闭服务器以后，页面还能用吗？已经打开的页面能继续用（声音和练习都在浏览器里），但点链接跳到别的页面会打不开，需要重新启动。

    右上角 ⚡ 上的数字是什么？正在运行的服务个数（包括其他标签页）。点开就能逐个停止，或者一键全部停止。

    引擎休眠后第一声慢了一点？唤醒通常不到 0.1 秒。如果练习时介意，可以把"音频引擎静默多久后休眠"调长一些，或者选"从不"。
